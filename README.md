# Generic Dynamic Vector in C

A generic dynamic array implementation in C that can store different data types using void*, dynamic memory allocation, and memcpy().

# Features:-

- Supports multiple data types, including int, char, float, and double.

- Dynamic memory allocation using malloc() and realloc().

- Add elements using push_back().

- Remove the last element using pop_back().

- Access elements using at().

- Replace existing elements using replace().

- Clear all elements using clear().

- Release allocated memory using destroy().

- Automatically increases capacity when the vector becomes full.
